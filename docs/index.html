What it does

An operator that lives on your desk, not in a tab.

01 Ask out loud, get a chart in the air

Speech to speech runs on Google Gemini Live, with lip-sync on the avatar. The model never writes numbers into a chart. It gets a viz_id, and the server builds the chart from real data inside a sandboxed iframe.

/

02 HQ, the command center

A terminal-style board with Stripe, Meta Ads, Gmail, Drive, GitHub and transcript panels. Built-in connectors cover Stripe, Meta Ads, Gmail, Drive, Docs, Calendar, GitHub and Postgres. You can drive the drill-downs by voice.

/hq

03 Agents you can watch at their desks

Quick research runs in-process on Gemini. Live browser jobs run in Browserbase Chromium. The Squad view is a pixel-art office where each agent shows what it is doing right now.

How it works

Your API keys stay on the server.

 Browser (hologram page)                 Node server (server.js)                Outside world
 mic → PCM 16 kHz ─────────▶ Gemini Live (ephemeral token from POST /session)
 ◀── voice 24 kHz ────────── │
 function_call ─────────────▶ POST /tool → src/tools/index.js ───────────────▶ Stripe · Meta · Google · Neon
 <iframe src=/viz/:id> ◀──── chart HTML built by src/kitchen
 transcripts ───────────────▶ /omo/ingest → event bus (/omo/ws) ─────────────▶ HQ · Squad · agents grid
  1. The page calls POST /session. The server mints a short-lived Gemini token, already bound to the persona, tools and voice. Your real key never reaches the browser.
  2. Audio streams directly between the browser and Gemini. Tool calls go back through /tool.
  3. Chart tools return a viz_id. The "kitchen" fills a hand-built template with real data.
  4. Transcripts and connector events go onto one event bus, which drives HQ, Squad and the agent grid.
Quick start

Boots with one key.

You need Node 20+ and a Gemini API key. Every other connector is optional and falls back to a mock or a clean "not configured" answer.

terminal
$ git clone https://github.com/harrythentrepreneur/omo-hologram.git
$ cd omo-hologram
$ cp .env.example .env      # set GEMINI_API_KEY
$ npm install
$ npm start                 # http://localhost:8080
Safety

Read this before you connect anything real.

Binds to 127.0.0.1

That is the default. The server can open agent terminals and read connected data, so set HOST=0.0.0.0 only on a network you trust.

No auth of its own

There is no login. Put your own auth in front of it before you expose it anywhere.

gmail_send sends real mail

When Gmail is connected, that tool sends real email. Leave Gmail unconnected, or use a test account, while you experiment.

Use read-only keys

The Stripe connector expects a restricted read-only key. The browser only ever gets short-lived Gemini tokens.
